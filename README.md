# 🌦️Global Weather & Early Disaster Warning System

A comprehensive, real-time meteorological platform built with **React**, **TypeScript**, and **Tailwind CSS**. Designed for both daily weather tracking and critical disaster preparedness, the application combines high-resolution weather models with early threat detection and localized emergency assistance.

---

### 🌟 Key Highlights

- **Real-Time Global Weather**: Accurate live conditions, hourly scrubbers, air quality index (AQI), wind speed & gusts, UV index, and solar cycles.
- **Early Cyclone & Monsoon Detection**: 7–14 day advance forecasting for tropical depressions, severe cyclonic storms, and cloudbursts across the Bay of Bengal, Arabian Sea, and global basins.
- **Local Emergency Services Directory**: Automatic location-aware helplines (Police, Fire, Disaster Management / NDRF / FEMA, Ambulance, and Coast Guard) with one-tap dialing (`tel:`) and custom local contact storage.
- **Interactive Weather Radar**: Live animated layers for precipitation, wind stream patterns, storm tracks, and coastal vulnerability zones.
- **16-Day Event & Occasion Planner**: Outdoor wedding, festival, travel, and sports planner with AI weather risk assessment and Google Calendar integration.
- **Severe Weather Alerts & Audio Sirens**: Multi-hazard emergency notifications with sound alert controls.
- **Responsive & Theme-Adaptive**: Optimized for mobile, tablet, and desktop with Dark, Light, and Solar Auto themes.

---

### 🛠️ Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Weather Data**: Open-Meteo API & Global Ensemble Forecast Systems
- **Storage**: Local browser persistence for custom contacts and user preferences
